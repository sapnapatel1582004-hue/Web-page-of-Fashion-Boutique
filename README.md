# 👗 Sapna Fashion Boutique

Sapna Fashion Boutique is a simple and elegant **fashion boutique website** created using **HTML and CSS**. The website provides a clean and user-friendly interface to showcase fashion collections and boutique information.

## 🌸 Pages Included

* 🏠 **Home** – Introduction to the fashion boutique.
* 👗 **Collections** – Displays the available fashion collections.
* 💖 **About** – Information about the boutique.
* 📩 **Contact** – Contact details and a contact section.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* Clean and attractive fashion-focused design
* Simple navigation between pages
* Responsive layout
* Multiple interconnected web pages
* Beginner-friendly HTML and CSS project
